# Dashboard SVG assets

The SVG images in web/static/assets were supplied by the project owner and were
originally obtained from SVG Repo. The project includes only the icons that
serve meaningful UI functions.

| Repository asset | Owner-supplied source filename | Usage |
| --- | --- | --- |
| ubuntu-logo.svg | ubuntu-svgrepo-com.svg | Ubuntu status and power |
| monitor.svg | monitor-television-svgrepo-com.svg | LG display status and controls |
| cpu.svg | cpu-free-material-2-svgrepo-com.svg | CPU & GPU Workload Manager |
| wifi.svg | wifi-svgrepo-com.svg | Connected network |
| wifi-off.svg | wifi-slash-svgrepo-com.svg | Disconnected or unavailable network |

The copied assets were sanitized for browser use: XML declarations, document
type references, CSS style blocks, event handlers and unsupported/external
elements or references were removed. Original path geometry was preserved.
No icons are loaded from external servers during app use.

SVG Repo's licensing varies by the individual icon, and the original icon
page URLs and licenses for every supplied asset were not included in the files.
Before redistribution outside this personal project or commercial publication,
verify the license terms of each exact icon on SVG Repo. The Ubuntu name and
brand mark remain trademarks of their respective owners.

Source: https://www.svgrepo.com/
